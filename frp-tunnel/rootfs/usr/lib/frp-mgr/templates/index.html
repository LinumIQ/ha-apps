Get Started

This add-on uses a secure browser-based pairing flow. No manual tokens or configuration files are needed.

  1. Click Start Pairing below.
  2. Open the link shown on screen in your browser (or scan the QR code if available).
  3. Sign in or create an account at app.linumiq.net.
  4. Approve the device when prompted.
  5. Come back here — your tunnel will be live!
